04需求与效率 / REBOUND02 需求与供给

推理更便宜，总资源需求会怎样？

先拆解任务数、调用次数、有效 token 与每 token 计算，再讨论需求反弹。

F ≈ Q × A × Leff × f

任务数 Q、每任务调用 A、有效长度 Leff、单位 token 计算 f，可能朝不同方向变化。

这里的假设

单位资源价格、任务组合与价格传导近似不变，故单任务价格 p ∝ r。

Q(p) ∝ p−ε
R = Qr ∝ r1−ε

若效率提高 k 倍，总资源变化为 kε−1。只有 ε > 1 时，本模型才出现净反弹。

判断有效任务、销售额和资源消耗是不同口径；市场收入还会受到价格与产品结构影响。

16研究选题 / DEFENSIBLE CONTRIBUTION06 研究与研讨

优先做可被强基线推翻的研究假设

GPU STA、流式 runtime 与 State Gateway 可以围绕同一个真实 ECO 闭环合作。

方向可能的研究贡献首先验证的缺口
CPU/GPU 自适应增量正确失效传播、前沿调度、性能区间和调度策略。真实瓶颈是否在传播；强 CPU 增量是否已覆盖收益。
显存约束下的流式 runtime工作集、驻留、重算与搬运的共同优化。跨模型复用能否成立；超显存时完整收益是否为正。
带证据的 State Gateway状态版本、失效闭包、事务与可重放语义。相对现有流程新增什么可验收能力；能否降低替换与错误定位成本。
电热／时序联合增量可组合边界模型、误差预算和跨域增量。模型访问、校准成本及联合分析的真实收益。
狭窄但完整的 Agent 闭环提案、验证、恢复和预算分配的稳定性。增加有效候选是否抵消调用、复核和失败成本。
判断论文贡献与独立产品成立是两张验收表；前者成立后仍可选择授权、集成或研究基础设施。
