雅可比矩阵

 定义(梯度)
 给定函数f  : Rn →R，且f在点x的一个邻域内有意义，若存在向
 量g ∈Rn 满足
                           f(x + p) −f(x) −gTp
                     lim            = 0,                   (1)
                   p→0        ∥p∥
 就称f 在点x 处可微．此时g 称为f 在点x 处的梯度.

 当f  : Rn →Rm 是向量值函数时，可以定义它的雅可比（Jacobi）矩
 阵J(x) ∈Rm×n，它的第i行是分量fi(x)梯度的转置，即
                ∂f1(x)   ∂f1(x)        ∂f1(x) 
                                                                  · · ·
                         ∂x1     ∂x2          ∂xn
                           ∂f2(x)   ∂f2(x)        ∂f2(x)
                                                                  · · ·
                 J(x) =    ∂x1     ∂x2          ∂xn      .
                                                                                                                                   ...                                      ...                                                            ...
                         ∂fm(x)   ∂fm(x)       ∂fm(x)                                                                                                                                                                     · · ·                                                   
                         ∂x1     ∂x2          ∂xn

广义雅可比


 假定Ω⊆Rn是开集，F : Ω→Rm是局部利普希茨连续的，根
 据Rademacher定理，F几乎处处可微的，故可引入广义微分的概念．

定义

 设F : Ω→Rm是局部利普希茨连续的, DF是F是可微点组成的集合,
 F在x 的B-微分可以被定义为

              ∂BF(x) :=  k→∞∇F(xk)|xklim        ∈DF, xk →x   .

 克拉克广义雅可比定义为B-微分的凸包

                      ∂F(x) = conv(∂BF(x)).

 容易看出，如果F : Ω→Rm 上局部利普希茨连续，则对任意x ∈Ω，
 广义雅可比∂F(x) 是非空紧凸集．

广义雅克比的性质



   对于利普希茨连续映射F : Rn →Rn, 如果F 是单调的，那么对于
   任何的x ∈Rn，∂BF(x) 中的每个元素都是半正定的．

   由于邻近算子是单调的，因此其广义雅克比矩阵是半正定。此
   外，由于其是非扩张的，还可以推出它们的特征值的界．

   设g 是Rn 上的适当的闭凸函数, F(x) = proxγg(x). 则对任意
   的J ∈∂F(x)，我们都有J 是对称半正定矩阵，且∥J∥2 ≤1．
   设g : Rn →R 是（块）可分的，即g可表示成：g(x) = Pni=1 gi(xi),
    其中xi ∈Rni，Pki=1 ni = n 是x 的所有分量的块划分)，
     则∂B(proxγg(x)) 和∂(proxγg(x)) 中的所有元素均为（块）对角矩
   阵．

半光滑性


 下面给出本章中最重要的一个概念——半光滑性的定义．

定义

 设F : Ω→Rm是局部利普希茨连续的，称F在x处是半光滑的，如果其
 满足
  (a) F在x点是方向可微的;
  (b) 对于任意的d和J ∈∂F(x + d),下面的关系成立

              ∥F(x + d) −F(x) −Jd∥= o(∥d∥), 当d →0.

 如果（b）被替换成对于任意的d和J ∈∂F(x + d)，下面的关系成立

            ∥F(x + d) −F(x) −Jd∥= O(∥d∥2), 当d →0.

 那么称F在x处是强半光滑的．

半光滑性




   半光滑性和强半光滑性在数乘、求和和复合运算下都是封闭的。

   光滑函数、所有的凸函数，分段连续可微的函数都是半光滑的。
   具有李普希兹连续梯度的可微函数，p范数∥· ∥p和分段线性函数是
   强半光滑的。一个向量值函数是半光滑的（或强半光滑的）当且
   仅当每个元素函数是半光滑的(或强半光滑的)。

   很多函数的邻近算子具有半光滑性和和强半光滑性
           ∥x∥1 与∥x∥∞的邻近算子映射是强半光滑的.
     多面体的投影是强半光滑的.
     对称锥上的投影是强半光滑的.
      在许多应用中,邻近算子是逐段C1 因此是半光滑的.

 Proof.
 当|x| ̸= µt 时，函数ϕ(x)是可微的，因此是强半光滑的．故只需要验证
 在两个不可微点，强半光滑性是成立的．对于x = µt，如果d > 0，则
 我们有x + d > µt，因此其广义雅克比为∂ϕ(x + d) = {1}，则对于任意

                        |ϕ(x + d) −ϕ(x) −Jd| = 0.

 因此可得在x = µt处，ϕ(x)是强半光滑的．类似的，可以证明x = µt也
 是强半光滑的．故ϕ(x)是强半光滑的．

求解非光滑线性方程组的半光滑牛顿算法


   许多算子分裂算法，比如近似点梯度法、DRS 算法等，等价于一
   个不动点迭代，其可以诱导一个非线性方程组

                                 F(z) = 0,                           (5)

    其中F(z) = z −T(z)，T为算子分裂算法对应的不动点映射．求解
   非线性方程组(5) 即能求解原始的复合优化问题．

 定义(求解非光滑方程组(5)的半光滑牛顿算法)
 假定F的是局部利普希茨连续的，则其广义雅克比存在．取F在zk点任
 意的广义雅克比矩阵Jk ∈∂F(zk)，若Jk可逆，其基本的迭代格式为

                           zk+1 = zk −J−1k  F(zk).                        (6)

   半光滑性也能保证牛顿型算法具有超线性收敛或二次收敛．

BD-正则性





定义
 如果F 在z 点所有B-微分的元素J ∈∂BF(z) 都是非奇异的，那么称F
 在z 点是BD-正则的．

 BD-正则性是一个非光滑方法局部收敛性分析的普遍假设.

假设

 定义在(5) 中的映射F在最优点z∗是半光滑的和BD-正则的．

 注：BD-正则的条件也可以换成是所有雅克比矩阵是非奇异的．

半光滑牛顿法的局部收敛性





引理

 如果假设1 成立，则存在常数c > 0，κ > 0 和一个小邻域N(z∗, ε0) 使
 得对于任意的y ∈N(z∗, ε0) 和J ∈∂BF(y)，下面的结论成立：
  (1) z∗是一个孤立解；
  (2) J 是非奇异的并且∥J−1∥≤c；
  (3) 局部误差界条件对于F(z) 在邻域N(z∗, ε0) 上成立，也就是
    说∥y −z∗∥≤κ∥F(y)∥．

半光滑牛顿法的局部超线性收敛性


定理

 设假设1 成立并且z∗是F(z) = 0的解．那么存在一个小邻域N(z∗, ϵ)，使
 得迭代(6) 是良定义的，且对于任意的k 有zk ∈N(z∗, ϵ)，迭代(6) 是超
 线性收敛的．如果F是强半光滑的，迭代(6) 是二次收敛的．

 Proof.
 根据引理1，迭代(6) 是良定义的．我们可以简单的推出

          ∥zk+1 −z∗∥ =  ∥zk −J−1k  F(zk) −z∗∥
             ≤  ∥J−1k ∥· ∥F(zk) −F(z∗) −Jk(zk −z∗)∥
             =  o(∥zk −z∗∥).

 其中最后一个等式来源于半光滑性．如果F是强半光滑的，则其可以改
 为O(∥zk −z∗∥2)

半光滑牛顿法


   针对凸优化问题，其广义海瑟矩阵是对称半正定的，因此可以选
   择任意的Jk ∈∂B(∇f(xk))，计算线性方程组

                                 (Jk + µkI)dk = −Fk                      (9)

   来得到半光滑牛方向．
   此时得到的牛顿方向为优化问题的下降方向，因此可以利
     用Armijo 线搜索准则选取步长，即选取最小的非负常数mk，满足

                    f(xk + ρmdk) ≤f(xk) −σρm∇f(xk)T∇f(xk),        (10)

    其中ρ, σ ∈(0, 1) 是给定的常数．取下一步的迭代点为

                              xk+1 = xk + ρmkdk.                    (11)

 Algorithm 1 求解优化问题的半光滑牛顿算法

   1: 给定参数0 < σ, ρ < 1
   2: 选择x0，设置k = 0
   3: while 没有停机时do
   4:  选择Jk ∈∂BF(zk)
   5:  选取µk > 0 求解牛顿方向dk 满足(9)
   6:  选取最小的非负常数mk 满足(10)
   7:  更新xk+1 根据(11)
   8:  设置k = k + 1
   9: end while

LASSO问题：基于近似点梯度法的半光滑牛顿算法

   由上述分析可知广义雅克比矩阵M(x)可以为一个对角矩阵，它的
   对角元素是

               (                                  1,  如果|(x −t∇h(x))i| > µt,
                   (M(x))ii =                                  0,  否则.

   为了方便表示，我们定义指标集合

            I(x) := {i : |(x −t∇h(x))i| > tµ} = {i : (M(x))ii = 1},
          O(x) := {i : |(x −t∇h(x))i| ≤tµ} = {i : (M(x))ii = 0}.

   则雅克比矩阵可以被表示成

                            t(∂2h(x))I(x)I(x)  t(∂2h(x))I(x)O(x)                 J(x) =                                                           .
                            0                      I

   利用雅克比矩阵分块结构，可以降低求解线性方程组的复杂度．

LASSO问题：基于近似点梯度法的半光滑牛顿算法


   令I = I(xk)和O = O(xk)，然后需求解方程组可以被表示为

               (1 + µk)skO = −Fk,O,
                (t(∂2h(x))II + µI)skI + t(∂2h(x))IOskO = −Fk,I.

   可以得到方程组的等价形式

                      1
                   skO = −       Fk,O,
                    1 + µk
                (t(∂2h(x))II + µI)skI = −Fk,I −t(∂2h(x))IOskO.

 实际上并不需要求解原始比较大的线性方程组，只需要求解规模
 为|I|的线性方程组即可．由于ℓ1范数能够保证问题(12) 的解是稀疏
 的，而指标集I恰好是解非零元的位置，因此在实际问题|I|是非常小
