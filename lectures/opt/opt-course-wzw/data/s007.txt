Linear Programming (LP)





 more succinctly

              Primal (P)                         Dual (D)

            min  c⊤x                    max  b⊤y
                    s.t.   Ax = b                                  s.t.  A⊤y + s = c
                     x ≥0                                     s ≥0

Weak duality



 Suppose

      x is feasible to (P)
       (y, s) is feasible to (D)

 Then

                           0 ≤  x⊤s  because xisi ≥0
                   =  x⊤(c −A⊤y)
                   =  c⊤x −(Ax)⊤y
                   =  c⊤x −b⊤y

                   =  duality gap

Key Properties of LP





     Strong duality: If both Primal and Dual are feasible then at the optimum

                               c⊤x = b⊤y ⇐⇒x⊤s = 0

     complementary slackness: This implies

                      x⊤s =  x1s1 + . . . + xnsn = 0  and therefore
                                   xisi =  0

complementarity





      Putting together primal feasibility, dual feasibility and complementarity together we
     get a square system of equations


                               Ax =  b,   x ≥0
                         A⊤y + s =   c,   s ≥0
                                                  xisi =  0   for i = 1, . . . , n

     At least in principle this system determines the primal and dual optimal values

Semidefinite Programming (SDP)





    X ⪰Y means that the the symmetric matrix X −Y is positive semidefinite


    X is positive semidefinite

                    a⊤Xa ≥0 for all vector a ⇐⇒X = B⊤B ⇐⇒

                                        all eigenvalues of X is nonnegative

Weak duality in SDP




      Just as in LP
                                     ⟨X, S⟩= ⟨C, X⟩−b⊤y

     Also if both X ⪰0 and S ⪰0 then

                           ⟨X, S⟩= Tr(XS1/2S1/2) = Tr(S1/2XS1/2) ≥0

     because S1/2XS1/2 ⪰0

     Thus
                                   ⟨X, S⟩= ⟨C, X⟩−b⊤y ≥0

Complementarity Slackness Theorem




    X ⪰0 and S ⪰0 and ⟨X, S⟩= 0 implies

                                   XS = 0

      Proof:
                             ⟨X, S⟩= Tr(XS1/2S1/2) = Tr(S1/2XS1/2)

     Thus Tr(S1/2XS1/2) = 0. Since S1/2XS1/2 ⪰0, then

                           S1/2XS1/2 = 0 =⇒S1/2X1/2X1/2S1/2 = 0
                                          X1/2S1/2 = 0 =⇒XS = 0

     Unlike LP we need some conditions for the optimal values of Primal and Dual SDP

Conic LP


 A set K ⊆Rn is a proper cone if
         It is a cone: If x ∈K =⇒ax ∈K for all α ≥0

         It is convex: x, y ∈K =⇒αx + (1 −α)y ∈K for α ∈[0, 1]

         It is pointed: K ∩(−K) = {0}

         It is closed

         It has non-empty interior in Rn

     dual cone:
                   K∗= {x | for all z ∈K, ⟨x, z⟩≥0}

===== PDF PAGE 29 | FOOTER [] =====
Conic LP



 Conic-LP is defined as the following optimization problem:
              Primal (P)                         Dual (D)

            min  c⊤x                    max  b⊤y
                    s.t.   Ax = b                                  s.t.  A⊤y + s = c
                     x ∈K                                     s ∈K∗
     For LP K is the nonnegative orthant

     For SDP K is the cone of positive semidefinite matrices

     For SOCP K is the circular or Lorentz cone

      In all three cases the cones are self-dual K = K∗
