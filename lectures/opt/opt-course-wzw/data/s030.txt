1  Algorithms for the group LASSO problem

Consider the group LASSO problem

                                         1
(1.1)                           min        −b∥2F + µ∥x∥1,2                                     x∈Rn×l  2∥Ax

where the data A ∈Rm×n, b ∈Rm×l and µ > 0 are given, and


                                             n
                                         ∥x∥1,2 = X ∥x(i, 1 : l)∥2.
                                                   i=1

Note that x(i, 1 : l) is the i-th row of the matrix x. Here, both x and b are matrices but they are written in small letters

for the convenience of coding. The test data are generated as follows:

    seed = 97006855;

    ss = RandStream(’mt19937ar’,’Seed’,seed);

    RandStream.setGlobalStream(ss);

    n = 512;

    m = 256;

    A = randn(m,n);
    k = round(n*0.1); l = 2;
    A = randn(m,n);

    p = randperm(n); p = p(1:k);

    u = zeros(n,l);  u(p,:) = randn(k,l);
    b = A*u;
    mu = 1e-2;
See http://bicmr.pku.edu.cn/˜wenzw/courses/Test_group_lasso.m
