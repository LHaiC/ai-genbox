       2020年秋季凸优化期中考试试题




要求：请写出详细的推导过程或证明过程。

1. （20分）证明集合

            K = {(x1, x2, x3) ∈R3   |  x2 > 0, x1 ≥x2ex3/x2} ∪{(x1, 0, x3)   |  x1 ≥0, x3 ≤0}

  为凸锥(convex cone)，写出并证明其对偶锥(dual cone)的具体形式。

2. （20分）证明：f(x) 是凸函数当且仅当对任意的x ∈dom f, v ∈Rn, g : R →R,

                                      g(t) = f(x + tv),  dom g = { t | x + tv ∈domf }

 是凸函数．

4. （20分）给定矩阵A ∈Rm×n，向量b ∈Rm, 向量c ∈Rn，以及标量d。假设至少存在一个x满足线性不等
  式Ax ≤b。证明下面两点的等价性：

     (a) 线性系统Ax ≤b的任意可行解x满足c⊤x ≤d.
     (b) 存在某一个p ≥0使得A⊤p = c且b⊤p ≤d.
