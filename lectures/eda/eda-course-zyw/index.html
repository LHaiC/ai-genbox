BOOLEAN ALGEBRA

固定一个输入，
看清整个函数。

从子函数到量词：把电路的“正确”变成可枚举、可证明的命题。

1.1 子函数不是一个数字

一个三输入布尔函数有 8 行真值表。固定其中一个变量，只消去一个自由度：例如固定 \(a=1\)，剩下的 \(F_{a=1}(b,c)\) 仍是一张有 4 行的真值表。只有再给定 \(b,c\)，它才变成一个 0 或 1。原 B·定义

香农展开像一个二选一开关。\(a\) 为 1 时只保留上面的子函数，为 0 时只保留下面的子函数。这里的“\(+\)”表示逻辑或，不是整数加法。

\[F=aF_{a=1}+\bar aF_{a=0}.\]

原例题 \(F(a,b,c)=ab+\bar ac\) 正好是一个 MUX：\(F_{a=1}=b\)，\(F_{a=0}=c\)。先切换输入，观察选中的子函数；然后点击真值表任意输出，把它改成另一个待研究函数。原 B·Quiz

1.2 三个运算，三个不同的问题

差分问的是翻转输入会不会改变输出；存在量词问能不能选择一个输入使输出为真；全称量词问无论怎么选，输出是否都为真。它们都只依赖两个子函数。原 B·布尔差分原 B·量词

\[\frac{\partial F}{\partial a}=F_{a=1}\oplus F_{a=0},\qquad \exists a\,F=F_{a=0}\lor F_{a=1},\qquad \forall a\,F=F_{a=0}\land F_{a=1}.\]

要小心“差分为 1”这一句话：它可以指当前剩余输入赋值下为 1，也可以指差分函数恒等于 1。前者是此处敏感，后者是所有剩余输入下都敏感。上面的表可以区分这两种意思。

展开看：为什么异或的差分可以分配？

将定义代入，利用异或的交换律与结合律：

\[\partial_a(F\oplus G)=(F_1\oplus G_1)\oplus(F_0\oplus G_0)=(F_1\oplus F_0)\oplus(G_1\oplus G_0).\]

对不同变量连续取差分，最终也是四个子函数的异或，所以次序不影响函数值。对 AND、OR 则不能直接照搬普通微积分的乘积规则；必须从两个子函数重新推导。原 B·性质

多变量展开：顺序不影响函数，不代表表示大小相同
\[F=abF_{11}+a\bar bF_{10}+\bar abF_{01}+\bar a\bar bF_{00}.\]

原例题的四个子函数依次是 \(1,0,c,c\)。交换展开顺序，计算的布尔函数不变；但在有子图合并的决策图表示里，变量次序可能影响图的大小。这是解释性补充，不是原文对实现规模的保证。原 B·香农展开性质

1.3 修复一个门，其实是在求一个量词命题

原课程希望实现 \(f(a,b)=ab+\bar b\)，用可配置 MUX 替换可疑门。四个配置位 \(d_0,\ldots,d_3\) 可以表达任意双输入逻辑门。这里明确约定：\(s_0=ab\)、\(s_1=\bar b\)、索引 \(k=2s_1+s_0\)，输出 \(G=d_k\)。原 B·网络修复

\[\exists\mathbf d\;\forall a,b:\quad \neg\bigl(G(a,b,\mathbf d)\oplus f(a,b)\bigr)=1.\]

配置必须先固定，再对所有输入正确。把量词顺序换成“每次输入都能找一套不同配置”，就不再是修复同一个电路。接下来尝试找出所有配置；留意某个 MUX 入口是否从来不会被选中。

公式拆解 · 解释性补充

把每个布尔符号翻译成一个可执行动作

\(F:\{0,1\}^n\to\{0,1\}\) 中，n是输入个数；\(\{0,1\}^n\) 是所有n位输入的集合，共有 \(2^n\) 种。\(x_i\) 是第i个输入，\(\bar x_i\) 是取反，乘积是AND，“+”是OR，“⊕”是XOR。它们不是普通实数加减乘除。

操作输入与输出为什么这样算
\(F_{x_i=v}\)固定一个变量，留下n−1变量函数限制真值表到该输入位等于v的那些行。
\((F\odot G)_{x_i=v}=F_{x_i=v}\odot G_{x_i=v}\)⊙可以是OR、AND、XOR固定输入后逐行做相同运算，两个步骤可交换。
\(\partial_iF=F_1\oplus F_0\)输出一个不再依赖xi的函数相同为0，不同为1：识别敏感性。
\(\exists x_iF=F_0\lor F_1\)至少一个分支为真两个可能选项做OR。
\(\forall x_iF=F_0\land F_1\)每个分支都为真两个可能选项做AND。

不是凭记忆套“求导法则”

\[\partial_x\bar F=\partial_xF,\qquad\partial_x(FG)=F_1G_1\oplus F_0G_0\]
\[\partial_x(F+G)=(F_1+G_1)\oplus(F_0+G_0)\]

不同变量的混合差分是四个子函数的异或：\(F_{11}\oplus F_{10}\oplus F_{01}\oplus F_{00}\)，故次序无关。一个常用链式关系也可以逐行验证：当 \(H(x,u)=G(F(x,u),u)\)、外层G不直接依赖x时，

\[\partial_xH=(\partial_xF)\cdot(G_{z=1}\oplus G_{z=0})\]

含义是：内部F必须被x翻转，外层G也必须对内部信号z敏感，最终输出才会翻转。存在直接x通路或多个耦合中间信号时，不能不加条件地套这一条。

给定布尔函数 \(F(a,b,c) = ab + \overline{a}c\)，使用香农展开对变量 \(a\) 进行展开，写出结果。

B03 · 原题
给定布尔函数 \(F(a,b) = ab + \overline{a}\)，计算 \(\frac{\partial F}{\partial a}\) 和 \(\frac{\partial F}{\partial b}\)。
原题出处 ↗

把两个端点的输出做异或，不是求实数导数。

关于 a：\(F_{a=1}=b\)，\(F_{a=0}=1\)，所以 \(\partial_aF=b\oplus1=\bar b\)。关于 b：\(F_{b=1}=a+\bar a=1\)，\(F_{b=0}=\bar a\)，所以 \(\partial_bF=1\oplus\bar a=a\)。

\[\boxed{\partial_a F=\bar b,\qquad \partial_bF=a}\]

b=1 时输出恒为1，翻转 a 不再有作用；a=0 时也一样，翻转 b 没有作用。这就是两个答案的电路直觉。

原题出处 ↗

B05 · 原题
布尔差分为 1 有什么含义？
原题出处 ↗

必须区分“这一行等于1”和“函数恒等于1”。

固定剩余输入 u 后，\(\partial_aF(u)=1\) 表示 \(F(1,u)\ne F(0,u)\)：只翻转 a 就会翻转输出。如果 \(\partial_aF\equiv1\)，则这一结论对所有 u 成立；如果只在某一行等于1，就不能推广到其他行。差分不表示“输出为1的概率”，也没有连续导数的正负方向。

B06 · 原题
给定布尔函数 \(F(a,b) = ab + \overline{a}\)，计算 \(\exists a F\) 和 \(\forall a F\)。
原题出处 ↗

同一对子函数：存在用 OR，全称用 AND。

仍有 \(F_{a=0}=1\)、\(F_{a=1}=b\)。

\[\exists a F=1\lor b=1,\qquad \forall a F=1\land b=b\]

a=0 总能使 F 为真，所以存在量词恒为真；只有 b=1 时，a 的两个取值才都能成功。因此全称消去 a 后留下的是函数 b，而不是一个固定答案。

B08 · 原题
存在量词为 1 有什么含义？
原题出处 ↗

至少一个选择成功；不要求同一个选择处处成功。

\((\exists aF)(u)=1\) 表示在当前 u 下，a=0、a=1 至少一个让 F 为真。即使 \(\exists aF\equiv1\)，成功的 a 也可能随 u 改变。例如 \(F=a\oplus b\)，每个 b 都能选 a 使输出1，但不存在一个固定 a 对所有 b 都成功：\(\forall b\exists aF=1\)，\(\exists a\forall bF=0\)。量词顺序决定“谁先选”。

2.1 两级逻辑：覆盖所有的 1，不碰任何的 0

课程的流程是 RTL → 技术无关综合 → 技术映射 → 网表。两级逻辑综合中的 SOP 是“若干乘积项的或”；POS 是“若干和项的与”。literal count 统计的是变量或其反相的出现次数，而不是不同变量的个数。原 S·综合流程原 S·两级化简

一个形如 1-0 的立方体代表 \(a\bar c\)：横杠表示该变量无关。两个只有一位不同的立方体可以合并，直到不能继续。随后仍需解覆盖问题：全部 prime implicant 的并集不一定是最小 SOP。

原题 \(ab+\bar ac+bc\) 的 literal count 是 6，但 \(bc\) 是冗余的共识项。下面使用真实的合并与精确覆盖枚举，不是预先写好的化简动画。只限三个变量，避免把指数级教学算法包装成大规模综合器。

2.2 多级逻辑与技术映射，不是同一道题

技术无关综合会做节点内化简、把小节点并入下游、提取公共因子。这些操作改变逻辑网络的形状。技术映射则问：在给定的门库中，用哪些实际门覆盖该网络？原文以面积、延迟等作为成本目标；下面的动态规划只实现可相加的面积型成本，不把门延迟直接相加当作整个设计时序。原 S·技术无关综合原 S·技术映射

\[C(v)=\min_{p\in\mathrm{Match}(v)}\left[c(p)+\sum_{u\in\partial p}C(u)\right].\]

\(v\) 是当前根节点；\(p\) 是一个在根处匹配的库门模式；\(\partial p\) 是模式没有继续覆盖、需要交给子问题的边界节点。自叶向根计算，确保子问题成本已经确定。这里用带 AND/OR/NOT 的可读树说明同一个递推；原文先把库与 subject 规范化为 NAND/NOT，原始模式图与式子保留在出处中。原 S·Matching

交换交换律运算的两个输入，不应让结果变贵——前提是匹配器确实尝试了非对称模式的所有合法旋转。对于 \((b+c)a\)，OA21 的“OR 那一侧”不能死板地绑在左边。原 S·非对称模式

2.3 为什么把 DAG 切成树可能损失信息？

原图中 \(X=b+c\) 同时供给 \(Y=aX\) 与 \(Z=Xd\)。共享一个 OR2 加两个 AND2 的成本是 \(3+2\times3=9\)；复制成两个 OA21 的成本是 \(2\times4=8\)。但若 OA21 单价改成 5，共享方案仍是 9，分别最优的两棵树却会总计 10。树内最优，不保证整个 DAG 最优。原 S·原图与成本题

这也说明“提取公共表达式一定更省面积”不是定理：还要看库里有没有更便宜的复合门。树覆盖的可分解性来自不重叠的子树，不能把跨输出共享节点偷偷当成两个独立对象。原文将一般 DAG covering 的困难与 tree covering 的 DP 对照，这里保留这个边界。原 S·Tree Covering

公式拆解 · 解释性补充

从表达式到网表：三种变换不要混淆

两级化简在单个节点里寻找更小的SOP/POS；多级化简改变节点之间的结构；技术映射则选择工艺库里能实现这些函数的真实单元。QM枚举精确候选，ESPRESSO是启发式方法；随变量数增加，最小项空间为 \(2^n\)，不宜把小例题的穷举当成大规模综合流程。

技术无关变换前后表达会发生什么
节点内部化简\(ab+\bar ac+bc\to ab+\bar ac\)删去冗余项，功能不变。
删除小节点／吸收\(u=a+b,z=uc\to z=ac+bc\)减少内部节点，可能增加literal或扇出负担。
增加节点／提取因式\(ab+ac\to u=b+c,z=au\)引入中间节点，literal计数由4降至3；库映射成本仍需另算。

逻辑网络节点可由SOP表示；netlist节点则必须是门库单元。两者都能表示相同布尔函数，但“节点少”“literal少”“面积小”“关键路径短”不是同一目标。

\[C(v)=\min_{p\in\operatorname{Match}(v)}\left[c(p)+\sum_{u\in\partial p}C(u)\right]\]
符号含义
v当前需要实现的子树根。
p在v处匹配成功的库门模式。
c(p)这颗库门的非负可加成本。
∂p模式停止覆盖后剩下的边界子树，不是微积分的偏导。
C(u)已由后序遍历算好的边界子树最优成本。

动态规划成立的关键是树的边界子问题不共享内部节点。一般DAG有共享扇出，分别计算子树可能重复收费或漏掉共享决策。原文将DAG covering的困难与tree covering的可分解性对照；这里不声称任意延迟、负载或布线约束也能用这个简单加法递推。

如果交换上面 subject tree 中节点 r 和 s 的位置，Cost(z) 会改变吗？为什么？

逻辑不变，匹配器也必须看见对称位置。

TimberWolf：短线、重叠、行容量

\[C=C_1+C_2+C_3,\quad C_1=\sum_e\operatorname{HPWL}(e)\]
\[C_2=\sum_{(i,j)\in\mathcal P}\bigl(O(i,j)+\alpha\bigr)^2,\quad C_3=\sum_r\lvert l(r)-d(r)\rvert^2\]

e是一个net；O(i,j)是两个单元的重叠面积；α是原文公式中的惩罚偏移；l(r)是第r行单元实际总宽，d(r)是目标宽。原文没有完整规定求和对集 \(\mathcal P\)、归一化与权重；若对全部单元对求和，O=0时α²是一个常数偏移，不能据此判断“仍有重叠”。这些项单位也不同，实际实现须用权重或归一化。这里保留原式并解释，不把实验06的简化目标叫做完整TimberWolf。

移动实际改变必须重新计算
M1 平移单元位置改变相关线长、重叠和行宽。
M2 交换两个单元相互交换位置两者连接和几何约束。
M3 旋转／改变朝向尺寸方向与引脚相对位置不是只改图标：pin位置与重叠也可能变化。

二次目标为什么能解线性方程？

\[W=\frac12\sum_{(i,j)}w_{ij}(x_i-x_j)^2\;=\;\frac12x^TQx-b^Tx+\mathrm{const}\]
\[\nabla W=Qx-b=0\quad\Longrightarrow\quad Qx=b\]

x是一列可移动单元坐标；Q汇总连接权重，非对角项反映耦合；b来自固定引脚锚定。y方向类似。若某个连通分量没有锚点，整组平移不改变能量，解不唯一。二次能量的单位是长度平方，不是布线长度；不能把HPWL直接代入这个固定二次式。

非线性目标：两个梯度在拔河

\[\nabla C=\nabla W+\lambda\nabla D\]
\[\frac{\partial W_\tau}{\partial x_j}=\frac{e^{x_j/\tau}}{\sum_i e^{x_i/\tau}}-\frac{e^{-x_j/\tau}}{\sum_i e^{-x_i/\tau}}\]

两个softmax分别把权重集中到最大、最小坐标，拉回两端。τ与坐标同单位，控制“软最大”的平滑尺度；\(0\le W_\tau-\mathrm{span}\le2\tau\log k\)。高斯密度教学代理中，σ决定排斥作用范围，\(\partial_{x_i}D=-\sum_{j\ne i}(x_i-x_j)e^{-\|p_i-p_j\|^2/(2\sigma^2)}/\sigma^2\)。梯度下降减去它，因而把近点推开；它不是原文提到的完整静电密度模型。

原文 FLUTE 的核心是把候选拓扑的长度写成坐标间隔的线性组合，从预计算集合挑选潜在最优候选。相对次序决定用哪组候选，实际坐标间隔仍决定哪条候选更短。“不关心具体坐标数值”只能理解为不按每一套坐标重新建立查找表，不能理解为计算线长时忽略间距。原 R·FLUTE

5.2 降频为什么能救 setup，却通常救不了 hold？

令发射时钟沿为 0，下一个捕获沿为 \(T+s\)，同周期捕获沿为 \(s\)，其中 \(s\) 是 capture 相对 launch 的时钟偏斜。AT 已包含 clock-to-Q 以及数据路径延迟，则：

在这个明确定义的单周期模型中，\(T\) 只出现在 setup 公式里；正 skew 有利于 setup，却使 hold 更紧。尝试只改变时钟周期，然后增加数据路径延迟：第二种操作可能修好 hold，却伤害 setup。

相同的数据量，
不同的等待时间。

访问顺序与映射规则，能让同一块缓存表现完全不同。

7.1 层次结构赌的是局部性，不是魔法

课程列出的层次是 L1 → L2 → L3 → DRAM → 二级存储。时间局部性意味着最近访问的数据可能很快再次访问；空间局部性意味着邻近地址可能被访问。memory wall 讨论处理能力与供数能力不匹配带来的限制，而不是某一级容量单独不足。原 M·存储层次

下面补充一个固定规则的组相联缓存：字节地址、write-free 读访问、LRU 替换。一个缓存块有 \(B\) 字节，\(S\) 个 set，每 set 有 \(A\) 路；容量是 \(BSA\)。

\[b=\lfloor\mathrm{addr}/B\rfloor,\qquad \mathrm{set}=b\bmod S,\qquad \mathrm{tag}=\lfloor b/S\rfloor.\]

每次访问先找 set，再在该 set 的所有有效路中比较 tag。容量足够并不意味着不会 miss：多个活跃块映射到同一个 set，可以互相替换。先运行“冲突”案例，增加路数，再比较相同总容量的不同组织。

7.2 从 cache miss 回到 CPU 时间

原课程把每条指令的存储停顿写成访问次数、未命中率和惩罚的乘积。注意这应是平均每条指令的 stall cycles，才能与 CPI 相加；不是整个程序的总停顿周期。原 M·Cache 公式

\[CPI=CPI_{\rm ideal}+a\cdot m\cdot p,\qquad T_{\rm CPU}=IC\cdot CPI\cdot t_{\rm clk}.\]

这里 \(a\) 是每条指令平均访问次数，\(m\) 是每次访问的未命中率，\(p\) 是每次未命中的额外周期数，与下方实验的定义一致。

下方可将实验14实际地址流的未命中率m传入公式。a始终是每条指令访问次数，m始终是每次访问的miss比例，p始终是额外周期惩罚。模型假设这些延迟没有重叠，不能不加修正地预测乱序、非阻塞cache或并行访存的真实性能。

先问miss rate的分母是谁

单层公式的m是“该层未命中次数÷该层访问次数”。多层中，L2局部miss rate只以到达L2的访问为分母；全局miss rate以最初L1访问为分母，两者不能混用。

t₁是首层查询时间；只有首层miss才付t₂；只有第二层也miss才付p₃。这里后两项均按额外代价定义。这个阻塞式递推是解释性补充，不是原网页提供的处理器测量。

缓存地址符号计算直觉
B：块字节数\(b=\lfloor addr/B\rfloor\)先确定地址在哪个连续块中。

PARALLELISM & MUTUAL EXCLUSION

更多的线程，
更多的约束。

一半是能快多少，另一半是是否仍然正确。

8.1 阿姆达尔定律：缩短一部分，不会缩短另一部分

把单处理器基线时间归一化为 1，可完美并行部分占 \(P\)，不可并行部分占 \(1-P\)。固定工作量、无额外开销时，\(N\) 个处理器的执行时间与加速比分别为：原 X·阿姆达尔

\[T_N=(1-P)+\frac PN,\qquad S_N=\frac{1}{T_N},\qquad S_\infty=\frac{1}{1-P}\;(P<1).\]

原习题 \(P=0.9,N=10\) 算出 \(S=100/19\approx5.263\)；要达到 5 倍至少需要 9 个处理器。不是把 90% 除以 10 得到 9% 后就忽略仍剩下的 10%。若 \(P=1\)，无开销理想上限不再有限。

“并行部分有 10% 额外开销”需要说明分母。

若开销等于理想并行耗时的 \(h\)，则 \(T_N=1-P+(1+h)P/N\)；若开销等于原始可并行工作时间的 \(h\)，则 \(T_N=1-P+P/N+hP\)。二者上限不同，原题未固定含义，不应只给一个无条件公式。

8.2 互斥、无死锁、无饥饿，是三层不同要求

共享访问中若存在冲突、又缺少正确同步，结果可能依赖线程交错。临界区需要排他的共享资源访问。“互斥”是任意时刻至多一个线程在临界区，允许暂时没有人进去。原 X·概念

Safety不能两人同时进入。
Deadlock-free有人申请，最终总有申请者进入。
Starvation-free每个持续申请者最终都能进入。

在相应执行与调度假设下，无饥饿比无死锁强。“大家都在等”与“总有人进去，唯独我进不去”是不同的失败。下例把每个共享变量读写做成一个可调度步骤，Peterson 的两个条件读取也分开。原 X·三个属性

8.3 两个不完整的想法，怎样组合成 Peterson？

LockOne 先声明意愿，再等对方不感兴趣：两人同时举手会死锁。LockTwo 只写 \(victim=i\)：独自申请时没有别人替它改 victim，也会等下去。Peterson 把两者结合：

flag[i] = true;
victim = i;
while (flag[j] && victim == i) { /* wait */ }
// critical section
flag[i] = false;

最后写 victim 的线程让步；另一个线程退出后放下 flag，等待者才获得机会。算法层面的保证依赖顺序一致的原子读写、线程继续被调度，以及临界区会结束。直接用普通 C/C++ 变量照抄会产生数据竞争；本实验不是弱内存模型或机器码验证器。原 X·LockOne原 X·LockTwo原 X·Peterson

证明线索：为什么两个人不能同时通过？

两人进入前都会先令自己的 flag 为 true。若两人同时在临界区，则双方 flag 都还没有清除。考虑两次写 victim 中较晚的一次：它把 victim 设成自己。在两人进入之前，对方没有新的本轮写 victim，因而晚写者在读到对方 flag=true 时不能通过 guard；若它曾读到 false，则对方更晚发布意愿并写 victim，对方成为晚写者而等待。这个次序分析消除了“两人都不等”的可能。

实验的穷举只检查每个线程申请一次的有限状态模型。90 个 Peterson 可达状态中没有两个 PC 同时在临界区，这是对实现的检查，不是无界执行、弱内存行为或无饥饿的形式证明。进展与有界超越还依赖调度、内存与有限临界区假设。

公式拆解 · 解释性补充

从时间份额读加速上限，从等待次序读正确性

P是单处理器基准时间里可并行部分的比例，不是代码行数比例；N是处理器数；S是同一工作量下 \(T_1/T_N\)。理想并行效率为 \(E=S/N\)。P=0时增加N没有帮助，P=1且无开销时S=N，P<1时上限有限。

\[S_\infty=\frac1{1-P},\qquad N\ge\frac{P}{1/s-(1-P)}\]

右式用于达到目标加速s，需分母为正并对N向上取整。目标等于有限渐近上限，通常只有N→∞才可能到达；超出上限没有满足条件的有限N。同步开销还会进一步缩小收益，且必须明确分母。

有 5 位哲学家，他们的一生都在思考和吃饭中度过。他们围坐在一张圆桌旁，桌子中间有一大盘米饭。然而，桌上只有 5 根筷子，摆放在每位哲学家之间。哲学家平时在思考。当一位哲学家饿了时，他会坐下来，试图拿起离他最近的两根筷子（左手一根，右手一根）。只有当他同时拿到两根筷子时，才能开始吃饭。吃完后，他放下筷子，继续思考。

如果每位哲学家都先拿起左手边的筷子，会发生什么情况？这是否满足互斥的三个属性？
原题出处 ↗

每个人拿住一根再等另一根，形成等待环。

当所有人都成功拿到左筷子后，各自等待右邻已持有的筷子，构成环形等待。若筷子获取本身是排他的，单根筷子的 safety 仍成立；但没有人能继续吃，deadlock-free 不成立，starvation-free 也不成立。并非“先左后右”的每次执行都死锁，而是它允许这个合法交错，已足以否定无死锁保证。

X06 · 原题

有 5 位哲学家，他们的一生都在思考和吃饭中度过。他们围坐在一张圆桌旁，桌子中间有一大盘米饭。然而，桌上只有 5 根筷子，摆放在每位哲学家之间。哲学家平时在思考。当一位哲学家饿了时，他会坐下来，试图拿起离他最近的两根筷子（左手一根，右手一根）。只有当他同时拿到两根筷子时，才能开始吃饭。吃完后，他放下筷子，继续思考。

思考：如何设计一个解决哲学家就餐问题的算法，以避免死锁和饥饿？
原题出处 ↗

去掉等待环只解决死锁；还需明确公平规则。

一种完整、易证明的方案是FIFO 服务员：饥饿请求排队；只有队首可在两根筷子都空闲时一次性拿到两根，拿不到就不占任何一根；吃完归还。不会出现拿一根等另一根的环。等待者不能被后来者插队；在已进餐者会结束、请求处理持续得到调度的前提下，每个有限位置的请求最终成为队首并获得资源。

另一方案是按筷子全局编号从小到大拿，消除循环等待，可无死锁；但仅靠编号顺序不能证明无饥饿，还要有公平锁或公平仲裁。服务员可能牺牲并发度，这正是简洁证明与吞吐之间的取舍。

X08 · 原题
如果两个线程几乎同时执行 Peterson 算法的 lock()，谁会进入临界区？
原题出处 ↗

双方都已举手时，最后写 victim 的线程让步。

若T0写victim=0，随后T1写victim=1，且两者flag都为true，那么T0看到victim≠0可以进入，T1看到victim=1继续等待；反过来则T1先进入。如果一方在另一方举手前已通过检查，也可能先进去。结论依据可观察的共享访问次序，不依据“几乎同时”这个模糊时间描述。

证明假设顺序一致的原子读写、线程持续获得执行机会且临界区有限。普通C/C++变量不能直接作为该假设下的实现。
